# Kauppalista

Yhteinen kauppalista-PWA. Julkaisu vaatii GitHub Pages -käyttöliittymän sekä Cloudflare Worker- ja D1-palvelut.

## Käyttöönotto

Siirrä sovelluksen frontend-tiedostot repositorion juureen. Luo Cloudflare D1 -tietokanta, ota Worker käyttöön ja määritä Worker-osoite käyttöliittymään. Ota GitHub Pages käyttöön asetuksista.
